# Natural Language to Bash Interface

This project provides a natural language interface to the bash command line. It uses the Gemini API to translate natural language queries into bash commands.

## Setup

1.  **Install dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

2.  **Set the Gemini API key:**

    ```bash
    export GEMINI_API_KEY=<your_api_key>
    ```

## Running the application

```bash
python main.py
```

The application will be available at `http://127.0.0.1:5000`.
